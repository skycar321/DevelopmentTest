# airflow-bundle 20260811_131508

배치 어드민 Airflow 제어 화면 + Airflow 번들 반입본입니다. 압축은 **헤더까지 암호화**(`-mhe=on`)되어 있고, 비밀번호는 이 저장소에 없습니다 — 별도 경로로 전달받으세요.

## 해제 절차

```bash
7z x airflow-bundle-20260811_131508.7z   # 비밀번호 입력 → airflow-bundle.tar.gz + docs/ + spring-batch-reference/
tar -zxvf airflow-bundle.tar.gz          # → airflow-bundle/{dags,plugins,config,scripts}
```

`docs/` 와 `spring-batch-reference/` 는 참조용이라 `deploy.sh` 에는 필요 없습니다.

## 이 판에 들어간 것

- **자동변환 운영 컬럼 재설계** — 나란히 놓여 뭘 하는지 읽히지 않던 세 버튼(독립 전환·큐 복귀·autogen 제외)을 폐기하고, **현재 상태 배지 + 단일 "변경" 진입점 + 라디오 선택 모달(승인 안내 포함)** 로 바꿨습니다.
- **승인 화면 정리** — 다섯 조각으로 나열되던 제목("활성/비활성 · 스케줄 · 설명 · 운영 매니페스트 · 자동 변환 운영 요청")을 **"운영 변경 요청"** 하나로 합쳤습니다.
- **불필요한 확인창 제거** — 정의 조회가 성공한 빌더 이동은 되돌릴 수 있는 화면 전환이라 확인창을 없애고 바로 이동합니다.
- **오류 문구 한글화** — 영문 기술 문자열(`Internal Server Error`, `Service Unavailable`)이 사용자 문구로 새던 것을 막았습니다. 다만 한국어 검증 문구에 섞인 형식 힌트(`HH:MM`)·식별자(`'second-task'`)·오류 코드(`RUN_TASK_STORE_FAILURE`)는 **그대로 보여 줍니다** — 감추면 무엇을 고쳐야 할지 알 수 없기 때문입니다.
- **데스크탑 전용** — 1024px 미만 검증 케이스 42건을 8계열에서 제외했습니다. 주력 해상도는 1440×900 과 1280×720 입니다.
- 온보딩 투어 입장별 갈림길(개발자/운영자), 상세 가이드 별도 층.
