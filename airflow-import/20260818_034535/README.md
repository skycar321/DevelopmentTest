## 4. 직전 판 §5 의 미결 — **6건 전부 종결**

직전 판에서 "지금은 정상 동작하지만 앞으로 그 부분을 건드릴 때 자동으로 잡히지 않습니다"라고
알려 드린 항목들입니다. 각각에 자동 검사를 붙였고, **검사가 실제로 결함을 잡는지**까지
일부러 결함을 만들어 확인했습니다.

| 직전 판 미결 | 지금 상태 | 결함을 만들어 확인한 내용 |
|---|---|---|
| `dataset(...)` 스케줄이 제출에서 쪼개짐 | 검사 있음 | 옛 코드로 되돌리니 `dataset('a'` / `'b')` 두 조각으로 쪼개지는 것을 검사가 잡음 |
| 배포 `[4c/5]` 실패가 묻힘 | 검사 있음 | 실패 상태를 남기는 줄 하나를 지우니 검사가 잡음 |
| 투어 화면의 빈 네모 | 검사 있음 | 숨김 규칙 한 줄을 되돌리니 네모가 다시 그려지는 것을 검사가 잡음 |
| 시험 찌꺼기가 반입물에 실림 | 검사 있음 | 차단 블록을 지우니 찌꺼기가 통과하는 것을 검사가 잡음 |
| StreamSets 태그 판정 | 검사 있음 | 판정 조건 하나를 지우니 대상에서 빠지는 것을 검사가 잡음 |
| 가이드 화면 설명과 코드의 일치 | 검사 일부 복구 | 표식 하나를 지우니 검사가 잡음 (아래 참고) |

### 가이드 화면 검사에 대해 — 솔직히 적습니다

가이드 화면(`/airflow/guide`)에는 "이 화면이 설명하는 내용이 실제 코드와 맞는지" 검사하는
장치가 원래 있었습니다. 그런데 화면이 개편되면서 **그 검사가 붙잡고 있던 자리가 사라져,
검사가 작동을 멈춘 상태로 오래 있었습니다.** 이번에 자동 변환 세 계열(Python·Spring·
StreamSets) 설명부터 되살렸습니다.

**나머지 항목은 아직 되살리지 못했습니다** — 운영 유틸 DAG 표, 운영 매니페스트 설명 등입니다.
화면 구조가 바뀌어 옛 방식으로는 붙일 수 없고, 순서대로 옮겨 붙이는 중입니다.
지금도 화면은 정상 표시되며, 다만 그 문단들의 설명이 코드와 어긋나도 자동으로는
잡히지 않습니다.
