## 반입 후 필수 조치 (둘 다 해당)

1. `batch-admin-reference/sql/airflow_control_ddl.sql` 재적용 — 멱등 ALTER
2. `sql/seed_templates.sql` 재적용 — **두 종류를 심는다**
   - 흐름 템플릿 15종
   - 파라미터 템플릿 11종(`{{ TODAY }}`·`{{ YESTERDAY }}`·`{{ 1,2,3,7,30_DAYS_AGO }}`·
     `{{ MONTH_FIRST }}`·`{{ MONTH_LAST }}`·`{{ PREV_MONTH_FIRST }}`·`{{ PREV_MONTH_LAST }}`)
   - 화면에서 15종만 확인하고 넘어가면 "전일/전월이 목록에 안 뜬다"는 지적이 그대로 재발한다
3. 배포는 기존과 동일: `./scripts/deploy.sh dev`
4. batch-admin은 Java 외에 **css/js/html/mapper.xml도 함께** 교체해야 반영된다

개발기 3.2.1 설치 절차는 `docs/migration/DEV_INSTALL_321_CHECKLIST.md` 참조.
