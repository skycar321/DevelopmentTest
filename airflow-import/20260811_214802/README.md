## 205721 대비 — 승인 화면을 좁은 해상도까지 맞췄습니다

1280×720 에서 한 화면에 보이는 승인 건수가 7건에 묶여 있었습니다. 원인은 예상과 달랐습니다.
- **승인·반려 버튼이 두 줄로 쌓이고 있었습니다.** 버튼이 각 56px 인데 처리 열이 99px 라 한 줄에 못 들어갔고, 그것이 행 높이를 79px 로 고정했습니다.
- 변경내용 열에서 4%를 처리 열로 넘기고 그 열의 줄바꿈을 막았습니다. **1440×900 과 1280×720 모두 기준을 충족**합니다.
- 함께 정리한 것: 변경내용 접힘 미리보기를 1줄로(전문은 `전체 보기` 로 그대로), `전체 보기` 버튼을 본문 끝에 인라인 배치.
