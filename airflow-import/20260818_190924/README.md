## 4. 반영 절차

직전 판과 동일합니다. 7z 전체 해제 → `batch-admin-reference/src/**` 등을 사내
`ui-batchadmin-main` 에 덮어쓰고 **jar 재빌드** → Airflow 서버는 `tar -zxvf airflow-bundle.tar.gz`
후 `./scripts/deploy.sh dev`. DB 반영(멱등)도 직전 판과 같습니다.

화면 스크립트와 도움말 화면이 바뀌었으므로 **재빌드가 필요**하고,
반영 후 브라우저 강력 새로고침(Ctrl/Cmd+Shift+R) 한 번 부탁드립니다.
