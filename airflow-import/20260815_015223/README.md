# Airflow 제어 반입판 (batch-admin + airflow-bundle)

## 1. 배치어드민(웹 화면) 반영
1. `airflow-bundle-20260815_015223.7z` 를 **전체 해제**합니다(비밀번호 필요).
2. 해제된 `batch-admin-reference/src/**`, `mapper/`, `static/`, `templates/`, `sql/` 을 사내 `ui-batchadmin-main` 원본 경로에 덮어씁니다.
3. **jar 를 재빌드**해 배포합니다. (⚠ Java 만 교체하면 이번 판 변경의 상당수가 반영되지 않습니다 — css/js/html/mapper.xml 이 함께 바뀌었습니다.)

## 2. Airflow 서버 반영
같은 7z 안의 `airflow-bundle.tar.gz` 를 Airflow 서버에 올려 해제한 뒤:

```bash
tar -zxvf airflow-bundle.tar.gz
cd airflow-bundle
./scripts/deploy.sh dev
```

`BASE_DIR`·`CONTAINER_RUNTIME`·`NEED_SUDO` 는 **자동 감지**되므로 따로 지정하지 않아도 됩니다.

## 3. DB 반영 (최초 1회)
```bash
psql -f sql/airflow_control_ddl.sql          # exec_dt 컬럼 추가 포함 (실행 이력 화면에 필요)
psql -f spring-batch-reference/sql/dag_task_map.sql
```
두 스크립트 모두 **멱등**이라 이미 적용된 환경에서 다시 실행해도 안전합니다.

## 4. 이번 판 변경 요약 (사용자 관점)

| 구분 | 내용 |
|---|---|
| 화면 안내(투어) | 우상단 **화면 안내** 버튼 복구, 첫 방문 시 자동 시작. 안내 문구가 실제 화면 이름과 일치하도록 정합(목록 새로고침·자동 실행 상태·요청 처리 상태). 한 요소를 여러 단계가 겨냥하던 중복 제거 |
| 실행 이력 화면 (신규) | 승인 관리에 **실행 이력** 탭 추가 — 실행 요청해서 승인받아 실제로 실행된 건만 조회. 기간·결과·검색 필터와 페이지 이동 |
| 실행 대기 취소 (신규) | 승인 후 실행 준비 상태에서 **취소** 가능. 취소 뒤 다시 요청할 수 있습니다 |
| 스트림셋 오표기 수정 | 예전 종료 상태가 남아 있으면 성공으로 찍히던 문제 수정 — 이번 실행이 실제로 돌았는지 확인한 뒤에만 종결 처리 |
| 승인 결과 표시 | 위임 처리(대기/성공/실패)와 최종 실행 상태를 결과 칸에 반영. 내부 경로가 없는 승인 건도 빈칸 대신 "반영됨" 표시 |
| 용어 일관성 | 화면 사이에서 같은 개념이 다른 말로 불리던 문제 정리 — **실행 시간 / 자동 실행 상태 / 요청 처리 상태** 로 통일(가이드·툴팁·모달·안내문 포함) |
| 목록 화면 | 보호 대상 배치는 기본 숨김 + **보호 DAG 보기** 토글, 숨겨진 개수 안내. 상단 버튼 행 제거, 열 겹침·잘림 정리 |
| 배치 만들기 | 배치 이름·설명·실행 시간·작업 단계가 준비되기 전에는 승인 요청 버튼이 비활성이며 이유를 안내 |
| 도움말 | 물음표 아이콘 대신 라벨에 마우스만 올리면 설명이 뜨도록 통일. 가이드 화면에서 검색 전에 "결과가 없어요" 가 떠 있던 문제 수정 |
