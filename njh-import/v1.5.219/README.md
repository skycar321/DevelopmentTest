## v1.5.218 대비 변경 — "진단은 셸이 알아서"

`bash start-local-llm.sh` 하나로 전 과정 자동:

1. **vulkan 오버레이 자동 탐색·설치** — 운영 ollama 에 없으면 노트북 안(패키지
   폴더·부모·ollama 폴더·Downloads 하위 폴더)을 뒤져 발견 즉시 dll 만 골라 설치.
   Downloads/바탕화면 **루트**에 풀린 경우엔 개인 파일이 섞이지 않게 자동 설치를
   거부하고 전용 폴더 안내(예: `Downloads\njh-vulkan` 에 풀면 자동 설치됨).
2. **떠 있는 serve 도 가속 실적용 검사** — 모델이 CPU 로 적재돼 있으면 자동으로
   트리 종료 → 가속 env 재기동. 종료가 안 되면(권한 등) 가짜 성공 대신 정직하게
   중단하고 관리자 권한 명령을 안내.
3. **적재 후 GPU 재판정 + 1회 자동 복구** — 그래도 CPU 면 serve 로그의 GPU 인식
   라인을 자동 출력(그 출력만 그대로 전달하면 됨). `/api/ps` 응답 지연은 "미적재"로
   오진하지 않고 판정 보류(정상 serve 를 죽이지 않음).
4. verify-local-llm.sh [6-1b]: 읽기 전용 자가진단 — 오버레이 유무·로그까지 자동 점검.
5. 견고성: taskkill 침묵 실패 교정(이전 버전들의 트리 종료가 Git Bash 에서
   무동작이던 결함), CRLF 판정 파일 내성, 판정 파일 상태 정직 표기.

## 노트북 절차

```bash
# 그냥 실행 — 진단·설치·복구 전부 자동:
bash start-local-llm.sh
# 마지막 줄이 "ok GPU 적재 확인 — VRAM N MB" 면 끝.
/c/njh-ollama/ollama.exe ps    # PROCESSOR "100% GPU" 재확인(선택)
```
