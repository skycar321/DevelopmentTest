## v1.5.206 → v1.5.208 델타

### 1. 설치 러너북 통합 — `설치가이드-통합.html` 하나로 4개 표면
게이트웨이·모델(AP01/02/03)·njh-cli·개인 PC 설치를 **시간순 러너북 하나**로 통합했습니다.
모든 단계가 WHERE(어느 기계·어느 경로) / WHAT(복붙 명령) / EXPECTED(성공 표식) / IF-FAIL(복구 명령) 4칸 형식입니다.

- 문서 상단 **"반입물 배치 지도"** 표: 어떤 파일을 어느 머신 어느 경로에 두는지 한눈에.
- ⛔ 구버전 운영 사본(`/data/llm/ollama/setup-model.sh` 등) 실행 금지 경고 — 반드시 새 킷 경로에서 실행.
- tar 해제 명령에 단일 파일 가드 추가: 게이트 tar가 2개 이상 남아 있으면 STOP 하고 이전 버전 삭제를 안내
  (와일드카드 해제는 tar가 2번째 파일을 아카이브 멤버로 오인해 실패).
- 문서의 모든 스크립트 명령은 배포본 실파일·실옵션과 자동 대조 검증됩니다(테스트로 강제).

### 2. 공정 큐(SR-01/03) — 한 세션의 게이트 독점 방지
게이트웨이 LLM 대기열에 **세션당 대기 2건 상한 + 세션 간 라운드로빈**을 도입했습니다.
여러 명이 동시에 쓸 때 한 사람이 큐를 独占해 다른 사람이 계속 밀리는 문제가 없어집니다.
같은 세션 안에서는 기존과 동일하게 도착순(FIFO)입니다.

### 3. keepAlive 24h 표준화 마무리
`ollama ps` 의 UNTIL 은 이제 `Forever` 가 아니라 **약 24시간 뒤 시각**으로 표시되는 것이 정상입니다.
현장 체크리스트·진단 기대값을 모두 이에 맞춰 갱신했습니다.
저메모리 노드(15Gi)는 러너북 표준 한 줄로 KV q8_0 opt-in:

```
NJH_OLLAMA_KV_CACHE_TYPE=q8_0 NJH_OLLAMA_FLASH_ATTENTION=1 ./install-all.sh model
```
