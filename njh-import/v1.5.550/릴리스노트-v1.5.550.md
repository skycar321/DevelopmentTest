## 이 키트가 담는 것

- v1.5.549 이후 허브에서 검증·통합된 변경 전체를 하나의 교체 키트로 전달합니다(소스 기준 v1.5.549 → v1.5.550 누적 통합). 핵심은 터미널 UI 4라운드(디자인 캔버스 3페이지의 5요소)와 게이트 결함 2건의 근본 수정입니다.

## 수신자 관점의 주요 변화

- **위험 심각도 토큰 통일**: 13개 점검 도구(PII 가드, 스프링 배치 재시작, 카프카 스키마 드리프트, 스레드·회복탄력성 가드 등)의 위험 표시가 하나의 공용 토큰 표(`riskToken`)를 거치며, 라이트 테마에서도 같은 색·글리프·라벨로 읽힙니다.
- **도구 활동 행의 의도 요약과 수치 우선 결과**: 파일 읽기·검색·편집·목록·상태·명령 실행 각각에 대해 "무엇을 하려는지" 한 줄과 "결과 수치" 한 줄이 두 물리 행으로 고정되어 표시됩니다(중간 말줄임 42컬럼 기준).
- **개인정보 가림 표시 규약**: 주민번호·전화번호 등은 자릿수 모양은 유지하고 원문 문자는 제거한 셀로 표시되며, 접힌 도구 행에는 `[PII N]` 건수 칩이, 상태 표시줄에는 누적 건수가 남습니다. 권한 확인 화면과 diff 출력도 같은 가림 형식을 사용합니다.
- **컴포저·상태 표시줄 정합**: 붙여넣기 크기 칩(`B`/`KB`), 기본·계획·승인·첨부 4상태 프롬프트 마커, 모델·컨텍스트·브랜치·처리량·백그라운드·폐쇄망 순서의 상태 세그먼트가 하나의 운영 상태 행렬에서 나옵니다. `@` 파일 완성에서 디렉터리를 인라인으로 펼치고 접을 수 있습니다.
- **서브에이전트 완료 접기와 인라인 탐색**: 여러 서브에이전트의 생명주기 행이 완료 시 한 줄로 접히고, 슬롯 대기는 "대기 중"으로 정직하게 표시되며, `[k/N]` 표기로 형제 세션을 순서대로 열어 정확히 선택한 세션을 재개합니다.
- **게이트 결함 근본 수정 2건**: 게이트 런처 테스트가 상위 게이트의 환경 변수를 상속해 실패하던 문제(테스트가 게이트 계약 변수를 전부 스스로 결정)와, 서비스 모듈 테스트가 클라이언트 소스 헬퍼를 가져와 모듈 경계 검사를 깨던 문제(패리티가 보장되는 스크립트 사본 사용)를 고쳤습니다.
- **게이트 보강**: 파이썬 프로브 종료 코드 전달, 부하에 비례하는 OCR 지연 단언, 시각 오라클 픽스처 안정화, 게이트 기록 원장의 브랜치 원본 보존이 포함되었습니다.

## DevAI(OpenCode 기반)와의 동일 모델 비교 절차

사내 Codi에는 DevAI와 njh-cli가 함께 쓸 수 있는 공통 모델 `[KTDS] Qwen3.8-Flash-Next`(262k 컨텍스트)가 있습니다. 두 도구를 같은 모델·같은 과제로 비교할 때는 다음을 지키십시오.

1. njh-cli용 Codi 앱은 **사고 모드를 끄고**, 창의성(temperature)은 0.2 안팎, 최소 출력 토큰은 1로 두십시오. 사고 모드가 켜져 있으면 사고 내용이 본문으로 흘러 출력이 흐트러지고 도구 호출 판정이 흔들릴 수 있습니다.
2. 같은 Vue 3 마이그레이션 과제 3~5개(예: 필터 제거, 이벤트 리스너 API 교체, 비동기 컴포넌트 선언)를 두 도구에 **같은 문장으로** 입력하고, 시간 제한을 두지 마십시오. 120초 같은 짧은 예산은 결과를 뒤집는 교란 변수임이 확인되었습니다.
3. 판정은 결과물의 빌드·테스트 통과 여부와 원본 소스 줄 손실 여부로 하고, 화면은 도구별로 캡처해 함께 보관하십시오. 화면 캡처는 `docs/사용자/06-post-import-first-30-minutes.md`의 증빙 보관 규칙을 따릅니다.
