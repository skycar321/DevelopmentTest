## 이 키트가 담는 것

- v1.5.564(전 키트)의 기능 전체에 더해, 아래 변경이 들어갔습니다. 구성은 이전 정식 키트와 동일합니다: 클라이언트(njh-cli), 게이트웨이(njh-gateway), 노트북 검증 킷(njh-win-laptop), Ollama Windows CPU 런타임, OCR 엔진, 빌드 매니페스트, SHA-256 매니페스트.
- 설치 절차와 현장값 관리 방식은 바뀌지 않았습니다. 현장값은 `~/.njh-cli/site.env` 한 파일에만 두고, 설치 명령은 용량 확인 → 전체 사전 점검 → 실제 설치 순서를 그대로 따릅니다.

## 수신자 관점의 주요 변화

- **작업 중 표시가 정리됐습니다**: 모델이 생각한 내용이 도구 그룹마다 다시 쌓여 화면을 채우던 것을 고쳤습니다. 이제 그룹 앞에 한 건만 보이고, 누계는 완료 줄 한 곳에만 남습니다. 중단 안내도 실제로 동작하는 키를 그대로 알려 줍니다.
- **화면 배정 마이그레이션 훅**: `bundled-hooks/vue3-migration/` 이 함께 나갑니다. 화면 단위 작업에서 채택 기록과 세션 종료 기록을 남기고, 커밋 메시지 규칙과 쓰기 범위를 훅으로 지킵니다. `settings.example.json` 의 `hooks` 항목을 기존 설정에 합쳐 쓰십시오.
- **표가 터미널에서 깨지지 않습니다**: 한글 터미널에서 표 구분선이 실제 칸 수의 두 배를 차지해 빈 줄처럼 보이고 오른쪽 경계가 줄마다 흔들리던 문제를 고쳤습니다. 해당 환경에서는 테두리를 ASCII 로 그려 본문과 같은 칸 예산을 공유합니다.
- **mintty 한글 글리프 안내**: Git Bash 기본 글꼴에서 한글이 벌어져 보이는 현상의 해결 방법을 설치 문서와 통합 설치가이드에 함께 넣었습니다.

## 서버에서 돌리기 전에

- Node.js 요건은 `22.13.0+` 로 변함이 없습니다. 분리 미션·`/goal` 운용 절차는 `서버-운영-가이드.md` 가 정본이고, 미션이 커밋까지 하게 하려면 `미션-git-쓰기-정책.md` 의 두 스위치를 모두 켜야 합니다.
- 키는 환경 변수에만 넣고 설정 파일에는 환경 변수의 이름만 둡니다. 키 값, 호스트, 조직명은 문서·로그·설정 파일에 기록하지 않습니다.

## 설치 전에 확인할 것

- 이전 키트에서 안내한 사전 점검·보관·거부 규칙이 그대로 적용됩니다. 처음 설치하거나 절차가 기억나지 않으면 키트에 동봉된 `통합-설치가이드`와 `02-설치-및-업데이트` 문서를 먼저 읽으십시오.
- 기존 서비스 디렉터리는 삭제하거나 덮어쓰지 않고 시각이 붙은 형제 디렉터리로 보존되며, Ollama 모델 저장소는 그대로 유지됩니다.
