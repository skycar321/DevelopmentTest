## 16차에서 고친 것

16차의 `05-draft.sh` 는 낡은 초안을 옆으로 옮기려다 실패해도 **그대로 진행**해서 같은 거부를
반복했다(`mv: Device or resource busy` → `DRAFT_REGISTRY_CHANGED` → 무한 반복).

- 옮기기에 실패하면 **즉시 멈추고 원인을 알려 준다**: VS Code 로 그 폴더를 열어 두었는지,
  다른 터미널이 그 안에 있는지, njh·npm 이 돌고 있는지, 탐색기 창이 보고 있는지.
- **이 셸이 초안 폴더 안에 있으면 시작 전에 막는다** — 가장 흔한 원인이다.
- Windows 는 열린 핸들이 있으면 폴더 이름을 못 바꾼다. **관리자 권한으로 올려도 풀리지 않는다**
  (권한이 아니라 사용 중이어서 막히는 것이다).

## 5단계를 돌리기 전에 닫을 것

1. VS Code 에서 `…-vue3-draft` 폴더를 열어 두었으면 닫는다(다른 폴더를 연다).
2. 다른 터미널이 그 안에 있으면 `cd /` 로 나온다.
3. njh-cli·npm 이 그 안에서 돌고 있으면 끝난 뒤 실행한다.
4. 파일 탐색기 창을 닫는다.
