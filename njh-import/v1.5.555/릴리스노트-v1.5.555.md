## 이 키트가 담는 것

- v1.5.554(전 키트)의 사내 OpenAI 호환 연결·상시 목표·분리 미션·무인 승인 계약 전체에 더해, **화면 정합 개선 16건(승인 화면·도구 결과 행·세션 목록·모델 선택·서브에이전트 진행 표시)과 Nexus 사전조사 스크립트의 사내 격리(차단) 목록 대조**가 들어갔습니다. v1.5.554를 아직 설치하지 않았다면 이 키트만 설치하면 됩니다.
- 구성은 이전 정식 키트와 동일합니다: 클라이언트(njh-cli), 게이트웨이(njh-gateway), 노트북 검증 킷(njh-win-laptop), Ollama Windows CPU 런타임, OCR 엔진, 빌드 매니페스트, SHA-256 매니페스트.
- 설치 절차와 현장값 관리 방식은 바뀌지 않았습니다. 현장값은 `~/.njh-cli/site.env` 한 파일에만 두고, 설치 명령은 용량 확인 → 전체 사전 점검 → 실제 설치 순서를 그대로 따릅니다.

## 수신자 관점의 주요 변화

- **Nexus 사전조사가 사내 격리(차단) 목록을 대조합니다.** 랜딩존 Nexus가 배포하는 두 마크다운 파일(차단 요약 목록·차단 상세 목록)을 `nexus-라이브러리-조사.sh`/`.ps1` 과 **같은 디렉터리**에 복사해 두면 스크립트가 파일 이름에 `QUARANTINE` 이 들어간 `.md` 를 스스로 찾아 읽습니다. 결과 파일의 `§10 사내 격리(차단) 목록 대조` 절에 현재 의존성·전환 계획표의 버전 가운데 격리된 것, 개선권고버전과 그 버전의 Nexus 보유 여부, 권고가 `N/A` 인 항목의 비격리 최신 후보, CVE 목록이 나옵니다. 목록 파일이 없으면 결론은 `격리 대조: UNKNOWN(목록 파일 없음)` 으로 표시되며 `0건` 으로 적히지 않습니다. 격리된 버전은 Nexus 가 여전히 내려 주더라도 이행 버전으로 선정하지 마십시오. 다른 위치의 파일은 `--quarantine-dir` 또는 `--quarantine-list` 로 지정합니다.
- **승인 화면에서 내부 제어값이 사라졌습니다.** `edit_file` 승인 상자와 키 안내 사이에 보이던 `review: false` 행은 내부 플래그였으며 더 이상 표시되지 않습니다. 승인 키 안내는 `[y/Enter]`·`[n/Esc]`·숫자 1/2/3 그대로입니다.
- **도구 결과 행의 숫자 표기가 일관됩니다.** `read_file` 요약 행의 줄 수가 바이트 수와 같은 천 단위 구분자로 표기됩니다(`1,935 lines`). `pii_guard` 결과 행에는 검사한 파일 수와 최고 위험 등급 배지가 붙습니다. 58열 좁은 폭에서 접힌 출력의 `(o)` 펼치기 안내가 잘리지 않습니다.
- **서브에이전트가 도는 동안 무엇을 하는지 보입니다.** 자식 에이전트가 실행 중일 때 일반 진행 바 대신 `⎿ [k/N] 실행 중 · 현재: <도구> <대상> · N toolcalls` 행이 표시되고, 끝나면 기존 완료 행으로 바뀝니다. 대기 중인 자식의 `대기 · 슬롯 k/N` 행은 그대로 유지됩니다.
- **세션 목록(`/resume`) 하단 안내가 한 줄로 유지됩니다.** 폭에 맞춰 중요도 순으로 안내를 골라 한 줄에 넣습니다. 100열에서는 이동·선택·닫기·삭제·검색·고정 안내가, 58열에서는 선택·닫기만 보이며 보이지 않는 키도 그대로 동작합니다. 세션 목록의 진행 표시는 다른 화면과 같은 유니코드/ASCII 판별을 따릅니다.
- **`/model` 목록이 항목마다 어느 백엔드인지 보여 줍니다.** 연결 단위로 묶인 제목 아래 각 모델에 백엔드 식별이 붙고, 하단 안내는 `Enter 적용 · Esc 뒤로` 입니다. 시작 배너의 백엔드 표기는 상태줄과 같은 연결 프로필 별칭을 씁니다(예: `● <모델>@local`).
- **`@` 파일 선택기의 디렉터리 항목에 자식 개수가 표시됩니다.** `[dir] — local directory · 14 files` 처럼 최대 99개까지 세고 그 이상은 `99+ files` 로 표기하며, 큰 디렉터리에서도 목록이 멈추지 않습니다.
- **플랜 모드 안내가 한국어로 표시됩니다.** 플랜 모드 진입 대화상자의 본문이 다른 화면과 같은 한국어입니다.

## 서버에서 돌리기 전에

- Node.js 요건은 `22.13.0+` 로 변함이 없습니다. 분리 미션·`/goal` 운용 절차는 `서버-운영-가이드.md` 가 정본입니다.
- 키는 환경 변수에만 넣고 설정 파일에는 환경 변수의 이름만 둡니다. 키 값, 호스트, 조직명은 문서·로그·설정 파일에 기록하지 않습니다.

## 설치 전에 확인할 것

- 이전 키트에서 안내한 사전 점검·보관·거부 규칙이 그대로 적용됩니다. 처음 설치하거나 절차가 기억나지 않으면 키트에 동봉된 `통합-설치가이드`와 `02-설치-및-업데이트` 문서를 먼저 읽으십시오.
- 기존 서비스 디렉터리는 삭제하거나 덮어쓰지 않고 시각이 붙은 형제 디렉터리로 보존되며, Ollama 모델 저장소는 그대로 유지됩니다.
