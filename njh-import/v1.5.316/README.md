## 이번 버전의 핵심 — 타겟점검 검토보고가 들어 있습니다

CLI 킷 안에 **`docs/타겟점검-AI-고도화-검토보고.html`** 이 동봉됐습니다. 압축을 풀고 브라우저로 그냥 열면 됩니다.
외부 CDN·폰트·이미지 참조가 0이라 폐쇄망에서도 그대로 열립니다.

**문서 최상단에 「사업부서 요청 — 그래서 어떻게 처리하는가」 요약 절이 있습니다.** 목차 첫 항목이기도 합니다.
그 아래는 전부 그 요약의 근거입니다. 바쁘면 최상단 절만 읽으면 됩니다.

요약 절이 답하는 것:

- 사업부서 안과 요청자 안이 각각 **어디까지 맞고 어디서 틀리는가**
- LLM 의 승부처가 `실판매자` 하나로 뚜렷한 이유 — 명의상 판매자(`sale_user_id`)와 실제로 판 사람이 다르고, 후자는 **필드가 아니라 본문 텍스트에만** 있다
- 일 1만 건 파일럿의 **처리 흐름과 실측 소요**(본문 1,000자 기준 3.19시간 → 야간 배치 안)
- 우리가 **지는 계약과 지지 않는 것**의 경계
- 지금 막혀 있어 **사업부서에 요청해야 할 5가지**

## 0. 먼저 받은 파일이 맞는지 확인 (풀기 전)

```bash
shasum -a 256 njh-cli-v1.5.316.7z njh-gateway-v1.5.316.7z njh-win-laptop-v1.5.316.7z
```

`SHA256SUMS.txt` 의 값과 **한 글자라도 다르면 풀지 말고 다시 받으십시오.**

## 1. 설치

```bash
# CLI 킷 (모든 사람)
7z x njh-cli-v1.5.316.7z -o"$HOME/njh-cli-v1.5.316"
cd "$HOME/njh-cli-v1.5.316"
bash setup.sh
"$HOME/.njh-cli/bin/njh" --version     # → 1.5.316 이 찍혀야 합니다

# 타겟점검 검토보고 열기
open docs/타겟점검-AI-고도화-검토보고.html      # Windows 는 start, 또는 브라우저로 드래그

# 노트북 로컬 LLM 도구
cd /c/njh-local-llm
./verify-local-llm.sh      # ← 먼저 이것부터
./start-local-llm.sh
njh
ollama.exe ps              # PROCESSOR 가 GPU 로 유지되면 끝

# 게이트웨이 담당자만
njh onboard gateway && bash "$HOME/.njh-cli/scripts/njh-connect-doctor.sh"
```

⚠️ **예전 버전 폴더의 `njh` 는 쓰지 마세요.** PATH 도 새 위치를 보게 하십시오.
버전이 섞이면 로컬 LLM 이 적재 옵션 불일치로 모델을 통째로 재적재하고, 그 재적재가 GPU 가 아니라 CPU 로 착지합니다.

## 3. 증명되지 않은 것 — 사내망에서만 확인 가능

인증된 Codi 호출, 사내 SQMS 조회, 게이트웨이 3대 함대 수용 시험은 **여기서 관측된 적이 없습니다.**
붙지 않으면 그것은 `BLOCKED_INTERNAL_NETWORK` 이지 PASS 가 아닙니다. 그렇게 기록해 주십시오.

⚠️ 이 킷은 v1.5.315 대비 파일 수가 319 → 309 입니다. 게이트웨이 설치가이드 등 일부 문서가
아직 머지되지 않은 다른 브랜치에 있어서입니다. **그 문서들이 필요하면 v1.5.315 킷을 함께 쓰십시오.**
