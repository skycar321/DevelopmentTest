## v1.5.212 → v1.5.213 델타 (시연 지적 전부)

1. **게이트웨이 무응답(348초) 근본수정** — 백엔드가 응답 헤더만 보내고 본문을
   안 보내면 30분까지 물려 있던 것을 **첫 바이트 120초 상한 + 다음 백엔드 자동
   재라우팅**으로 교체. **서버 킷 재설치가 필요한 유일한 항목.**
2. Codi 툴콜: 역할 계약 상시 전송 기본값(설정 3플래그 false 기본).
3. `│` 세로줄이 단계마다 한 줄씩 쌓이던 것 — 빈 인용줄 렌더 제거로 근본수정.
4. 스피너 제자리 고정 — 어떤 경로로 그려져도 1초/바퀴 회전 보장.
5. "Budget 0%" → "컨텍스트 [게이지] N% 사용" (컨텍스트 창 사용률).
6. 시작 시 "백엔드 연결 실패(fetch failed)" 오탐 — 실호출과 같은 전송 스택으로
   사전점검, 실패해도 "△ 사전점검 실패(호출은 계속 시도)"로 완화.
7. /connection 의 유령 codi1/codi2 숨김.

서버: 기존 위에 njh-gateway 킷 재설치(설치가이드-통합.html 절차 그대로).
PC/노트북: 압축 풀어 교체. DB는 기존 ~/.bashrc sqms_jdbc_* 그대로(추가 작업 없음).
