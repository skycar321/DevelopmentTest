# njh-import v1.5.235 — 노트북 킷 (긴급 수정: VRAM 판독 버그)

- CLI 킷: **v1.5.226 폴더** 그대로 / gateway: **v1.5.218 폴더** 그대로.

## ⚠️ v1.5.234 를 이미 설치하셨다면 반드시 이걸로 교체하세요

v1.5.234 튜너는 **모든 GPU 조합을 "적재부터 GPU 에 안 들어감"으로 오판**합니다.
실제로는 GPU 에 잘 올라가는데, 튜너가 ollama 응답에서 VRAM 값을 못 읽어서
생긴 버그입니다(응답 안에 `details:{...}` 가 끼어 있는 형식을 처리하지 못했습니다).
그 상태로 끝까지 돌리면 잘못된 "CPU 운용" 판정이 저장됩니다.

수정 내용:
- 응답 파싱 기준 교정 + **파싱에 실패하면 "GPU 아님"으로 단정하지 않는** 폴백 추가
- 실제 ollama 응답 형식으로 재검증(파서 6케이스 + 전 경로 실행 검증)

## 반입 후

```bash
cd /c/njh-local-llm
./setup-local-llm.sh        # 전 조합 스윕 (20~40분)
```

v1.5.234 로 이미 돌려 잘못된 판정이 저장됐더라도, 이 버전의 setup 이 자동으로
다시 측정합니다. 마지막 표를 사진으로 주시면 됩니다.

빠르게 확인만 하려면: `NJH_TUNE_FAST=1 bash tune-gpu-ctx.sh` (첫 통과에서 중단)
