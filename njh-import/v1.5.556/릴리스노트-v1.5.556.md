## 이 키트가 담는 것

- v1.5.555(전 키트)의 사내 OpenAI 호환 연결·상시 목표·분리 미션·무인 승인 계약 전체에 더해, **사내 첫 실행 캡처(2026-09-08 오전)에서 확인된 결함의 수정과, `/goal` 미션이 자기 브랜치에 커밋·푸시까지 할 수 있는 git 쓰기 옵트인, Vue3 마이그레이션 스킬 정식 동봉(참조 148·목표 문서 포함), Nexus 재측정 킷 e 스크립트**가 들어갔습니다.
- 구성은 이전 정식 키트와 동일합니다: 클라이언트(njh-cli), 게이트웨이(njh-gateway), 노트북 검증 킷(njh-win-laptop), Ollama Windows CPU 런타임, OCR 엔진, 빌드 매니페스트, SHA-256 매니페스트.
- 설치 절차와 현장값 관리 방식은 바뀌지 않았습니다. 현장값은 `~/.njh-cli/site.env` 한 파일에만 두고, 설치 명령은 용량 확인 → 전체 사전 점검 → 실제 설치 순서를 그대로 따릅니다.

## 수신자 관점의 주요 변화

- **연결 프로필에 전송 방식이 명시됩니다.** `settings.json` 의 각 연결 프로필에 `transport: "openai" | "dify"` 가 생겨, 프로필 이름이 `openai` 로 시작하지 않아도(예: 사내 DevAI 프로필) 시작 사전점검과 대화가 같은 OpenAI 호환 경로를 씁니다. 전 키트에서 `/connection` 으로 손수 전환해야 했던 문제가 이것입니다. 키 값이 `apiKeyEnv` 에 들어가 있으면 설치 시 경고합니다.
- **설치가 기존 `settings.json` 을 새 규격으로 올려 줍니다.** 번들 기본값을 바탕으로 기존 값을 매핑해 넣고, 원본은 버전 붙은 백업으로 보존하며, 무엇이 매핑됐는지 보고합니다. 사용자가 규격을 손으로 맞출 일이 없습니다.
- **개인정보 표시 마스킹은 기본 꺼짐입니다.** `tools.piiGuard.enabled` 의 기본값이 `false` 로 바뀌었고, `작성일: 2026-09-08` 같은 날짜가 계좌번호로 오인돼 `■■■■-■■-■■` 로 가려지던 오탐도 함께 사라졌습니다. 필요하면 설정에서 명시적으로 켤 수 있고 `/doctor` 가 현재 상태를 한 줄로 보여 줍니다.
- **승인 화면이 선택 메뉴가 됐습니다.** `[y/Enter/1] 승인 … [d] 전체 diff` 식 나열 대신 `승인 · 거부 · 항상 허용 · 더보기` 한 행을 방향키로 고르고 Enter 로 확정합니다(Esc 는 거부, y/n/a 단축키는 그대로). "항상 허용" 의 적용 범위가 고르기 전에 보이고, 승인 뒤 출력은 두 줄을 넘지 않습니다. 셸 명령은 상자 안에 전체가 표시되며 잘리지 않습니다.
- **넓은 화면에서 diff 가 화면 밖으로 나가지 않습니다.** 새 파일이거나 한 줄이 반 폭을 넘는 한글 내용이면 좌우 분할 대신 위아래(unified) 로 보여 주고, 승인 상자의 테두리 여백을 계산에 넣습니다.
- **파일 쓰기·수정 뒤 실제로 기록된 내용이 번호와 함께 보입니다.** 승인 때 본 diff 와 별개로, 성공한 쓰기만 번호 붙은 미리보기를 남깁니다.
- **여러 줄 초안 뒤 Enter 를 빠르게 두 번 눌러도 입력이 유실되지 않습니다.** 한 패킷으로 들어온 연속 Enter 를 순서대로 처리합니다.
- **`/goal`·`njh mission` 이 git 커밋·푸시를 할 수 있는 옵트인이 생겼습니다.** 기본은 여전히 차단입니다. 설정 `tools.git.write` 를 켜고 **동시에** 실행 시 `--allow-git-write` 를 주어야 하며, 허용 브랜치 패턴·보호 브랜치·강제 푸시 금지 규칙이 적용됩니다. 정본: `미션-git-쓰기-정책.md`.
- **Vue3 마이그레이션 스킬이 정식 동봉됩니다.** 스킬 참조 문서·스크립트·`/goal` 목표 문서(`assets/goal-vue3-draft.md`)·분리 미션 레시피(참조 148) 가 들어 있고, 사내 원본 식별자는 계약 파일 템플릿으로 대체돼 있습니다. router/bootstrap, `v-model` 이벤트 계약, 읽기 후 쓰기 순서와 변환 결과물 경로, 완료 스캔 규칙을 따릅니다. `COMPLETED_UNVERIFIED` 상태에서는 완료와 배포를 허용하지 않습니다.
- **Windows Terminal 에 `njh-cli` 프로필이 자동 등록됩니다(Windows 만).** 설치가 Fragment 파일로 드롭다운 항목을 추가하고(기본 프로필은 바꾸지 않음) 설치된 D2Coding 글꼴과 색상표를 씁니다. `--skip-terminal-config` 로 끌 수 있습니다. 정본: `윈도우-터미널-프로필.md`.
- **비대화형 실행에서도 이미지·문서를 첨부하고 스킬을 지정할 수 있습니다.** `njh -p "…" --image 캡처.png --json`, `--attach 명세.pdf`, `-p "/vue3-migration <요청>" --image 캡처.png --json` 이 한 번의 요청으로 모델에 전달되고 답이 JSON 으로 돌아옵니다. PDF 등 바이너리 문서도 OpenAI 호환 경로에서 인라인 `file` 파트로 전송되며(합산 5MB), 점검 절차는 `사내-비대화형-첨부-검증.md` 가 정본입니다. 전 키트에서는 스킬 슬래시 실행이 모델을 호출하지 않고 빈 답으로 끝나고, PDF 첨부가 Dify 업로드 경로로 빠져 실패하던 결함이 있었습니다.
- **시작 직후 Node 경고가 화면에 나오지 않습니다.** 잘못 설정된 주소로 리다이렉트가 반복될 때 나던 `MaxListenersExceededWarning` 의 원인을 고쳤고, 남는 런타임 경고는 `/alerts` 로 모입니다.
- **Nexus 재측정 킷 e 스크립트**(`nexus-라이브러리-조사.sh/.ps1`) 가 인자 없이 동봉된 `package.tobe-20260908.json` 을 대상으로 격리 목록을 자동 발견해 조사하며, 결과 파일은 결론만 남기고 근거는 별도 파일로 분리합니다.

## 서버에서 돌리기 전에

- Node.js 요건은 `22.13.0+` 로 변함이 없습니다. 분리 미션·`/goal` 운용 절차는 `서버-운영-가이드.md` 가 정본이고, 미션이 커밋까지 하게 하려면 `미션-git-쓰기-정책.md` 의 두 스위치를 모두 켜야 합니다.
- 키는 환경 변수에만 넣고 설정 파일에는 환경 변수의 이름만 둡니다. 키 값, 호스트, 조직명은 문서·로그·설정 파일에 기록하지 않습니다.

## 설치 전에 확인할 것

- 이전 키트에서 안내한 사전 점검·보관·거부 규칙이 그대로 적용됩니다. 처음 설치하거나 절차가 기억나지 않으면 키트에 동봉된 `통합-설치가이드`와 `02-설치-및-업데이트` 문서를 먼저 읽으십시오.
- 기존 서비스 디렉터리는 삭제하거나 덮어쓰지 않고 시각이 붙은 형제 디렉터리로 보존되며, Ollama 모델 저장소는 그대로 유지됩니다.
