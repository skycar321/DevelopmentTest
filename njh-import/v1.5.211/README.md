## v1.5.210 → v1.5.211 델타 — 대기 표시·픽커 UX 5건

### 1. 대기 스피너가 사라지던 회귀 근본수정
안내/경고 라인이 하나라도 찍히면 대기 스피너가 **영구히 사라지던** 회귀
("처음만 보이고 끝") — 이제 라인이 찍혀도 스피너가 그 아래에서 계속 돕니다.

### 2. 스피너 1바퀴 = 1초
회전 주기를 1.5초 → 정확히 1초/바퀴로 통일.

### 3. 응답 대기 중 진행 라인 상시 출력
하단 고정 상태표시줄이 없는 터미널(Git Bash 등)에서도 **15~30초마다
`… 응답 대기 Ns — 모델이 프롬프트를 읽는 중입니다 · 계속 기다립니다`** 라인이
남습니다(스크롤백·캡처에도 찍힘). 멈춘 게 아니라 기다리는 중임을 항상 확인 가능.

### 4. /mode 화살표 선택
인자 없이 `/mode` 를 치면 ↑/↓ 화살표 픽커가 뜹니다(현재 모드 표시, Enter 선택, Esc 취소).

### 5. /skills 등 목록 페이지 전환 밀림 해소
페이지가 넘어갈 때 화면이 줄줄이 밀리던 것 — 프레임을 한 번에 그리도록 원자화했습니다.

## 추가: 내장 GPU(Vulkan) 실험 패키지 — `njh-vulkan-igpu-ollama-v0.32.1.7z`

**노트북 로컬 LLM 전용 실험**입니다(선택 사항, 서버와 무관). ollama v0.32.1의
Vulkan 백엔드 라이브러리 + 설치안내(`INSTALL-VULKAN.md`) + A/B 측정 스크립트
(`measure-igpu-ab.sh`) 동봉. `C:\njh-ollama\lib\ollama\vulkan` 에 폴더를 넣고
`OLLAMA_NO_CLOUD=1 OLLAMA_VULKAN=1 OLLAMA_IGPU_ENABLE=1 ollama serve` 로 켠 뒤 (IGPU_ENABLE 없으면 내장 GPU 를 드랍함) `bash measure-igpu-ab.sh` 를 돌리면
CPU vs 내장GPU 속도 비교표와 채택/폐기 판정이 나옵니다. 결과 표 사진만 공유해 주세요.
암호는 다른 킷과 동일합니다.

> ⚠️ v0.32.1의 모델 추천 기능이 ollama.com 을 조회하다 사내 차단 페이지가 503 WARN 으로
> 로그에 찍힐 수 있습니다 — 민감정보 발신이 아니며, `OLLAMA_NO_CLOUD=1` 을 붙이면 사라집니다.
