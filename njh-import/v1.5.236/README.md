# njh-import v1.5.236 — 게이트웨이 킷 (모니터 "경과" 수정)

- 노트북 킷: **v1.5.235 폴더** 그대로 (이 폴더에는 없습니다).
- CLI 킷: **v1.5.226 폴더** 그대로.

## 무엇이 바뀌었나

모니터 화면의 **경과 시간이 0 → 4초 → 0 으로 되돌아가던 문제**를 고쳤습니다.

원인: 게이트웨이는 한 요청을 처리하다 실패하면 **다른 백엔드로 재시도**하는데,
그때마다 실행 기록의 시작 시각을 "지금"으로 다시 찍고 있었습니다. 그래서 재시도가
일어날 때마다 경과가 0 으로 초기화됐고, 사용자가 **실제로 기다린 시간**을 볼 수
없었습니다. 이제 **요청이 도착한 시각**을 기준으로 세므로, 재라우팅이 몇 번
일어나도 경과가 이어집니다.

> 참고: 모니터의 "시작 시각"이 njh-cli 화면의 "프롬프트 분석 중" 시작과 같아 보이고
> 최초 대기 시작과 다른 것도 같은 원인이었습니다.

## 설치 (AP03)

기존 게이트웨이를 쓰던 방식 그대로 교체하면 됩니다.

```bash
# 1) 기존 게이트웨이 정지
bash stop.sh

# 2) 새 아카이브를 같은 디렉터리에 풀기 (설정 파일은 유지됩니다)
# 3) 재기동
bash start.sh
bash status.sh      # 상태 확인
```

설치 후 모니터 화면에서 처리 중인 요청의 "경과"가 되돌아가지 않고 계속 증가하는지
확인해 주세요.

## 서버 3대 중 어디에

게이트웨이는 **AP03 에만** 설치돼 있습니다(AP01/02 는 모델 백엔드 전용). 이 킷도
AP03 에만 적용하면 됩니다.
