## 21차에서 고친 것

**(1) `SERVE_OK 000000` — 응답이 없는데 합격 도장이 찍혔다.**

HTTP 코드는 세 자리여야 하는데 여섯 자리가 나왔다. 원인은
`$(curl … || echo 000)` 이다. curl 은 연결 실패 시 `%{http_code}` 로 **이미 `000` 을
출력하면서 종료코드도 0이 아니라**, `|| echo 000` 이 덧붙어 `000000` 이 된다.
그러면 `[ "$CODE" != "000" ]` 판정이 통과한다 — **실패가 성공으로 바뀐다.**

→ `http_code` 헬퍼가 **정확히 세 자리**만 돌려준다. 응답 없음은 반드시 `000`.

**(2) 7단계가 키를 환경변수에서만 찾았다.**

키가 `~/.njh-cli/settings.json` 의 `apiKey` 에 정상적으로 있는데도
"환경변수 NJH_OPENAI_CHAT_KEY 가 비어 있다" 로 멈췄다. 바로 앞 `05a` 는 같은 키로
잘 돌아간 뒤였다. 키 위치는 설정마다 다르므로 **위치로 판정하면 안 된다.**

→ 5a·8c·8-review 와 같은 방식으로, **실제로 한 번 물어보고** 판정한다.
   환경변수든 설정 파일이든 답하면 통과한다.
