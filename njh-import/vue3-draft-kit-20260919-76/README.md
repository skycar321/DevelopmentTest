## What changed

- **라이브러리 전환이 어디까지 끝났는지 실측으로 확정했다 — 계획 문서가 틀려 있었다.** 그동안 "아직 할 일" 로 남아 있던 항목들을 랩 to-be 트리에서 하나씩 재 보니 상당수가 **이미 끝난 상태**였고, 문서만 옛 상태였다. ① PDF 저장 라이브러리는 **선언도 설치도 이미 목표 버전(0.14.0)** 이고 함께 쓰는 두 의존성도 이미 설치돼 있다. Vue 2 전용 래퍼는 선언도 import 도 없다 — "보안 상향" 은 **할 일이 아니라 끝난 일**이다. 설치본 진입 소스를 옛 판과 바이트 단위로 대조해 **호출 모양을 바꿀 필요가 없다**는 것도 확인했다(달라진 곳은 내부 클론 구현·삽입 HTML 정화·지연 10ms). 다만 이건 **서명 호환의 증거일 뿐 출력이 픽셀까지 같다는 증명이 아니다** — PDF 저장 결과는 리포트 화면에서 눈으로 본다. 매니페스트가 고정하는 것은 범위(`^`)이고 4.x·3.x 의 구체 판은 해석 결과다 — "매니페스트가 그 버전을 핀했다" 고 적지 않았다. 공개 취약점 DB 재조회는 하지 않았으므로 "취약점 없음" 으로 읽어서는 안 된다.
- **결정 맵 수치 정정 — 이제 문서가 아니라 결정 맵을 센다.** 75건의 분류는 교체 20 · 제거 19 · 신규 17 · **상향 11 · 유지 6** · 조건부 제거 2 다. 75차까지 문서 여러 곳에 적혀 있던 상향·유지 숫자는 PDF 라이브러리 결정을 고치기 **전**의 값이었다. 게이트가 이제 결정 맵(`tools/library-decisions.ko.json` 의 `kind`)을 직접 세서 킷 문서의 숫자와 다르면 **패키징을 막는다** — 같은 종류의 낡은 숫자가 다시 남을 수 없다.
- **남은 라이브러리 잔여는 스프레드시트 계열뿐이다(실측).** 화면 진입점(main·라우터)에서 닿는 201개 파일을 전수 스캔해, 교체·제거로 결정했는데 **아직 쓰이는 것**은 두 가지(스프레드시트 라이브러리 43곳 · 그 스타일 포크 1곳)뿐이고 **둘 다 엑셀 작업 소유**로 이 차수 범위 밖이다. 그 밖의 교체·제거 대상은 선언도 import 도 없다. 브라우저 모듈 그래프(빌드 시점에 해석된 995개 모듈 기록)도 같은 결론이다 — Node 내장 모듈(`fs`·`stream`·`crypto`)을 끌고 오는 경로는 그 두 가지뿐이고, 쿼리 문자열 라이브러리 쪽 경로는 **라이브러리가 스스로 브라우저에서 막아 둔 의도된 폴백**이라 shim 을 지어 넣을 대상이 아니다(없는 위험을 만들어 고치지 않았다).
- **스타일 포크 둘을 동시에 끌고 오는 파일은 없다.** 한 화면에 두 포크가 함께 적혀 있다고 알려져 있었지만, 실제로 한쪽 import 는 **주석 처리**돼 있고 활성은 하나뿐이다. 제거 순서를 잡을 때 주석 쪽은 **소스 변경 없이 선언만** 빠지는 행이다. 세 번째 포크는 선언도 import 도 없다.
- **22단계 새 분류 `library-vuex` — 화면에 남은 옛 상태관리 호출을 이미 있는 스토어 동작으로 잇는다.** 리터럴 인자 2개짜리 로그인 dispatch 만, 그리고 대상 스토어에 해당 **비동기 동작이 실제로 있을 때만** 바꾼다. 이름공간·동적 이름·객체 형태·인자 3개·스프레드 인자·옵셔널/계산 접근·중첩 일반 함수·이름 충돌·`script setup` 은 **반쪽 수정 없이 거부**하고 사유와 함께 사람 확인으로 남긴다. **인증 정책은 한 줄도 바꾸지 않는다** — 목표 동작은 비밀번호 인증을 의도적으로 거부하며, 옛 Vue 2 소스가 만들던 가짜 신원은 **되살리지 않았다**. 이것은 인증 구현이 아니라 **문법 다리**다. 그래서 잔재 검사의 옛 상태관리 항목은 0 이 되지 않고 **줄어든다**(못 바꾼 getter·commit 은 남는다) — 줄면 정상이다.
- **엑셀 축 자동 전환 규칙을 한 칸 넓혔다.** "수집한 행 배열을 표로 넘기기 **전에** JSON 으로 복사하는" 모양을 자동 전환 범위에 넣었다. 랩 실측으로 자동 전환 **10 → 11/44**, 검토 **34 → 33**. 추적 중인 배열·밖에서 온 행·콜백을 거친 행·이름이 가려지는 경우·표를 만든 **뒤** 복사하는 경우는 **동일성을 증명하지 못했으므로 그대로 거부 상태로 남겼다** — 넓히기 쉬운 쪽으로 넓히지 않았다. 관련 테스트는 4 → 9건으로 늘렸고, 실제 라이브러리를 돌려 **값·시트 이름·호출 순서**까지 옛 경로와 대조한다.
- **게이트 보강.** ① 새 분류가 **첫 실행에서 커밋을 만들고 두 번째 실행에서는 바꿀 것이 없는지**(멱등), ② 바꾼 파일에 옛 호출이 남지 않고 목표 동작을 부르는지, ③ **지원하지 않는 모양을 손대지 않았는지**, ④ 전수 스캔의 잔여가 **줄었는지**와 남은 것이 스프레드시트 계열뿐인지, ⑤ 결정 맵 수치와 문서가 맞는지, ⑥ 반입 절의 명령 순서가 계약과 같은지를 전체 사슬 리허설에서 확인한다. 새 단언은 **개수를 박는 대신 "줄었는지 / 0 인지"** 로 썼다 — 개수를 박아 둔 단언이 직전 차수까지 게이트를 네 번 막았고, 그중 하나는 **합격할 때만 죽는** 모양이었다.
