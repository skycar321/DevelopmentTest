## 이 키트가 담는 것

- v1.5.562(전 키트)의 기능 전체에 더해, 아래 변경이 들어갔습니다. 구성은 이전 정식 키트와 동일합니다: 클라이언트(njh-cli), 게이트웨이(njh-gateway), 노트북 검증 킷(njh-win-laptop), Ollama Windows CPU 런타임, OCR 엔진, 빌드 매니페스트, SHA-256 매니페스트.
- 설치 절차와 현장값 관리 방식은 바뀌지 않았습니다. 현장값은 `~/.njh-cli/site.env` 한 파일에만 두고, 설치 명령은 용량 확인 → 전체 사전 점검 → 실제 설치 순서를 그대로 따릅니다.

## 수신자 관점의 주요 변화

- **Vue 3 초안 스킬 갱신(랩 tip f591bd4e)**: 얼럿 부품 채택이 별칭 클래스가 붙은 헤더 슬롯 공지까지 인식해 78 → 90/90 이 됐고, 인식하지 못하는 형태는 거부 대신 건너뛰어 같은 화면의 다른 공지 채택을 막지 않습니다. 엑셀 관련 스킬 테스트 11파일 중 9파일을 실제 수정으로 통과시켰고, 나머지 2파일은 과거 오라클에 고정된 재현 단정임을 문서화했습니다.
- **번들 비식별 도구 보강**: 이미 비식별된 디렉터리 옆에 원본 이름 디렉터리가 다시 들어와도 병합해 처리합니다(동기화 절차 스크립트화).

## 서버에서 돌리기 전에

- Node.js 요건은 `22.13.0+` 로 변함이 없습니다. 분리 미션·`/goal` 운용 절차는 `서버-운영-가이드.md` 가 정본이고, 미션이 커밋까지 하게 하려면 `미션-git-쓰기-정책.md` 의 두 스위치를 모두 켜야 합니다.
- 키는 환경 변수에만 넣고 설정 파일에는 환경 변수의 이름만 둡니다. 키 값, 호스트, 조직명은 문서·로그·설정 파일에 기록하지 않습니다.

## 설치 전에 확인할 것

- 이전 키트에서 안내한 사전 점검·보관·거부 규칙이 그대로 적용됩니다. 처음 설치하거나 절차가 기억나지 않으면 키트에 동봉된 `통합-설치가이드`와 `02-설치-및-업데이트` 문서를 먼저 읽으십시오.
- 기존 서비스 디렉터리는 삭제하거나 덮어쓰지 않고 시각이 붙은 형제 디렉터리로 보존되며, Ollama 모델 저장소는 그대로 유지됩니다.
