## 수신자 관점의 주요 변화

- **터미널 UI 개선**: 세션의 라이브 활동 표시, 서브에이전트 형제 세션 탐색, 좁은 폭(20~32컬럼)에서의 도구 행·작업 블록 배치, 붙여넣기 중 개행 처리, 진행 표시(스피너)의 출력 소유권 정리(접근성 모드 포함), 시작 화면의 짧은 뷰포트 보존이 포함되었습니다.
- **명령행 옵션 우선순위 정합**: `--model` 지정이 로컬(Ollama) 모델 설정과 일관되게 동기화되고, 백엔드 종류·엔드포인트·API 키·keep-alive 재정의 순서가 회귀 테스트로 고정되었습니다.
- **검증 원장과 컴플라이언스**: `njh ledger status`로 최근 검증 부채 현황(검증 후 반환·한도 소진·거부 건수)을 볼 수 있고, `njh compliance verify-ledger`로 로컬 hash-chained 컴플라이언스 원장을 검증할 수 있습니다. 정책 거부(민감 경로·개인정보·DB 외부 전송)는 원문 없이 정규화된 결정 기록으로 감사 로그에 남습니다.
- **검증 통과 전 반환 거부(MCP)**: MCP 서버에 `verified_delegate` 도구가 추가되어, 위임한 작업이 검증 계약을 통과하기 전에는 결과를 반환하지 않습니다. 취소와 진행 상황 보고를 지원합니다.
- **다중 백엔드 합의 워크플로우(선택 기능)**: 설정의 `workflow.consensus`를 명시적으로 켠 경우에만 동작하며, 백엔드별 슬롯 예산 안에서 여러 후보를 병렬로 받아 검증 후 종합합니다. 기본값은 꺼짐이고 켜지 않으면 기존 동작과 동일합니다.
- **매치·OCR 서비스 안정성**: 게이트웨이 응답 본문 상한, MCP stdio 응답 검증, OCR 어댑터 응답 디코딩 경계가 강화되었습니다.
- **릴리스 키트 안전장치**: 아카이브 입력 검증, Ollama 런타임 아카이브 무결성 검증, 배포물 유출 사전 점검, 실패한 키트 디렉터리 보존, `SHA256SUMS.txt` 기반 채널 인벤토리 검사가 추가되었습니다.
- **수신자 문서**: 설치 가이드에 `--mcpapi` 명시 조건과 HTTP 엔드포인트의 TLS 생략 경계가 문장으로 추가되었고, 번들 스킬 문서(Vue 3 마이그레이션)의 분할 정리와 Nexus 라이브러리 조사 결과 문서가 포함되었습니다.

- 이전 키트에서 안내한 사전 점검·보관·거부 규칙이 그대로 적용됩니다. 처음 설치하거나 절차가 기억나지 않으면 키트에 동봉된 `통합-설치가이드`와 `02-설치-및-업데이트` 문서를 먼저 읽으십시오.
