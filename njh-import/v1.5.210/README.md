## v1.5.209 → v1.5.210 델타 — 현장 시연에서 나온 5건 전부 반영

### 1. Codi 툴콜 미발화(터미널 챗봇화) 근본 수정
Codi 앱에 프롬프트가 "사전 등록됐다"는 설정이 켜져 있으면 도구 **형식 계약**(`<tool_call>` 지시)까지
생략되던 것을 — 앱 프롬프트가 비었거나 무시되면 모델이 형식을 몰라 산문으로만 답함 —
**형식 계약은 항상 전송**으로 변경. 실제 요청 캡처로 와이어 탑재 검증 완료.
여전히 산문만 나오면: `bash scripts/njh-toolcall-doctor.sh` 실행 후 판정 박스만 사진으로 공유.

### 2. 모델 왕복 시간 상시 표시
도구 실행 시간만 보이고 모델 대기(프리필)가 무표시라 "멈춤"처럼 보이던 것 —
이제 매 라운드 `↩ 모델 응답 X.Xs` 줄이 남습니다(모델 재적재 포함 여부도 표시).

### 3. tool_search 응답 상한(6KB)
모델이 스키마 20개를 한 번에 요청해 18.3KB가 다음 프롬프트에 실려 CPU 프리필로
수 분 멈추던 함정 — 상위 매치 스키마만 남기고 점진 강등.

### 4. 과거 반입 잔재 자동 정리
설치·상주 검증 후 `install-all.sh`가 이전 회차의 tar·미참조 모델 저장소를
`legacy-<날짜>/`로 자동 이동(삭제 아님, 현역 저장소·incoming 불가침). 세 노드 공통.

### 5. 모니터 자정 표기 수정
오류 타임라인의 "24:30:16" → "00:30:16" (h23 강제).
