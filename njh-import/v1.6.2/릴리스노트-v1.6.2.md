## 이 키트가 담는 것

- v1.6.1(전 키트)의 기능 전체에 더해, 아래 변경이 들어갔습니다. 구성은 이전 정식 키트와 동일합니다: 클라이언트(njh-cli), 게이트웨이(njh-gateway), 노트북 검증 킷(njh-win-laptop), Ollama Windows CPU 런타임, OCR 엔진, 빌드 매니페스트, SHA-256 매니페스트.
- 설치 절차와 현장값 관리 방식은 바뀌지 않았습니다. 현장값은 `~/.njh-cli/site.env` 한 파일에만 두고, 설치 명령은 용량 확인 → 전체 사전 점검 → 실제 설치 순서를 그대로 따릅니다.

## 수신자 관점의 주요 변화

- **`vue3-migration` 번들 스킬을 Vue 3 초안 킷 42차와 같은 판(`f06614a85f`)으로 맞췄습니다**: v1.6.1 이후 스킬 스크립트에 들어간 수정 6건이 이 키트에 실립니다 — (1) Windows 에서 `npm.cmd` 를 직접 spawn 하면 Node 22 가 `EINVAL` 로 거부해 초안 빌드 게이트가 **빌드 로그 없이** `DRAFT_BUILD_GATE_FAILED` 로 끝나던 결함을 `npm-cli.js` 직접 실행으로 고침(`npm_invoke.mjs`, 세 호출 지점 공통), (2) 부트스트랩 조립을 전부-아니면-전무에서 **화면별 거부**로 바꿔 등록 모양 밖 화면 1개가 `main.js` 를 Vue 2 로 남기던 결함 해소, (3) CRLF 체크아웃 입력을 LF 로 정규화(모듈 5개가 거부되던 원인), (4) 1단계 드라이버 `--only-file`(파일별 격리 워크트리 병렬 워커), (5) original-preimages 핀 갱신(낡은 핀이 5단계 전체 거부를 내던 결함), (6) 핀 출처 문서 정정.
- **Vue 3 초안 킷 실행에 이 키트가 필수는 아닙니다**: 킷은 자기 스킬 사본(`bundled-skills/vue3-migration`)을 쓰므로 42차 킷은 v1.6.1 위에서도 동작합니다. 다만 `~/.njh-cli/skills/vue3-migration` 을 대화형 스킬로 직접 부르는 경우에는 이 키트로 갱신해야 킷과 같은 동작을 얻습니다.
- **클라이언트 실행 파일의 기능 변경은 없습니다**: v1.6.1 이후 `src/`·런처·설치기 변경이 0건이라 번들은 버전 스탬프만 다릅니다. 설치 절차·현장값 관리 방식은 그대로입니다.

## 서버에서 돌리기 전에

- Node.js 요건은 `22.13.0+` 로 변함이 없습니다. 분리 미션·`/goal` 운용 절차는 `서버-운영-가이드.md` 가 정본이고, 미션이 커밋까지 하게 하려면 `미션-git-쓰기-정책.md` 의 두 스위치를 모두 켜야 합니다.
- 키는 환경 변수에만 넣고 설정 파일에는 환경 변수의 이름만 둡니다. 키 값, 호스트, 조직명은 문서·로그·설정 파일에 기록하지 않습니다.

## 설치 전에 확인할 것

- 이전 키트에서 안내한 사전 점검·보관·거부 규칙이 그대로 적용됩니다. 처음 설치하거나 절차가 기억나지 않으면 키트에 동봉된 `통합-설치가이드`와 `02-설치-및-업데이트` 문서를 먼저 읽으십시오.
- 기존 서비스 디렉터리는 삭제하거나 덮어쓰지 않고 시각이 붙은 형제 디렉터리로 보존되며, Ollama 모델 저장소는 그대로 유지됩니다.
