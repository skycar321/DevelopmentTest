## 이 키트가 담는 것

- v1.5.557(전 키트)의 사내 비대화형 첨부·스킬 호출 수정, 시작 경고 억제, TUI 승인·시작 화면 개선 전체에 더해, **Vue3 마이그레이션 스킬의 2차 정식 동봉(허브 전용 48경로 보존, ExcelJS 참조 164, 공통화 3차 마감, 분리 미션 메카닉스 문서, 사설 프리이미지 출하 제외)** 이 들어갔습니다.
- 구성은 이전 정식 키트와 동일합니다: 클라이언트(njh-cli), 게이트웨이(njh-gateway), 노트북 검증 킷(njh-win-laptop), Ollama Windows CPU 런타임, OCR 엔진, 빌드 매니페스트, SHA-256 매니페스트.
- 설치 절차와 현장값 관리 방식은 바뀌지 않았습니다. 현장값은 `~/.njh-cli/site.env` 한 파일에만 두고, 설치 명령은 용량 확인 → 전체 사전 점검 → 실제 설치 순서를 그대로 따릅니다.

## 수신자 관점의 주요 변화

- **Vue3 마이그레이션 스킬이 2차 갱신됩니다.** 스킬 참조·스크립트·자산이 랩 최신 상태로 갱신되고(허브에만 있던 48개 경로 복원, ExcelJS 기반 엑셀 다운로드/업로드 참조 164, 공통화 3차 단위와 참조 101), `/goal` 분리 미션의 진행표·재개(resume) 메카닉스가 목표 문서에 반영됐습니다. 사내 원본 식별자와 사설 프리이미지는 출하 입력에서 제외돼 있습니다.
- **릴리스 아카이브 누출 검사가 런타임 표현식을 오탐하지 않습니다.** 쿠키 조회식·검증 팩토리 매개변수·정규식 매치 속성 같은 코드 표현 4종을 자격증명 값으로 오인하던 것을 협소하게 바로잡았고, 실제 리터럴 자격증명은 여전히 차단됩니다(경로 예외 없음).
- **분리 미션 목표 문서의 읽기·재개 계약이 고쳐졌습니다.** `/goal` 목표 문서(`assets/goal-vue3-draft.md`)와 참조 148 이 문서 전체 읽기(페이지 단위 read_file, 잘림 금지), 재개 우선순위(진행표·체크포인트를 먼저 읽고 첫 미완료 행부터), git 단독 명령·기준 SHA 확인 규칙을 명시합니다. 랩의 실제 미션 실행(attempt 4/5)에서 확인된 문서 잘림·재개 지시 충돌·브랜치 생성 정책 불일치에 대한 수정이며, 런타임 코드는 바뀌지 않았습니다.

## 서버에서 돌리기 전에

- Node.js 요건은 `22.13.0+` 로 변함이 없습니다. 분리 미션·`/goal` 운용 절차는 `서버-운영-가이드.md` 가 정본이고, 미션이 커밋까지 하게 하려면 `미션-git-쓰기-정책.md` 의 두 스위치를 모두 켜야 합니다.
- 키는 환경 변수에만 넣고 설정 파일에는 환경 변수의 이름만 둡니다. 키 값, 호스트, 조직명은 문서·로그·설정 파일에 기록하지 않습니다.

## 설치 전에 확인할 것

- 이전 키트에서 안내한 사전 점검·보관·거부 규칙이 그대로 적용됩니다. 처음 설치하거나 절차가 기억나지 않으면 키트에 동봉된 `통합-설치가이드`와 `02-설치-및-업데이트` 문서를 먼저 읽으십시오.
- 기존 서비스 디렉터리는 삭제하거나 덮어쓰지 않고 시각이 붙은 형제 디렉터리로 보존되며, Ollama 모델 저장소는 그대로 유지됩니다.
