## 이 키트가 담는 것

- v1.6.3(전 키트)의 기능 전체에 더해, 아래 변경이 들어갔습니다. 구성은 이전 정식 키트와 동일합니다: 클라이언트(njh-cli), 게이트웨이(njh-gateway), 노트북 검증 킷(njh-win-laptop), Ollama Windows CPU 런타임, OCR 엔진, 빌드 매니페스트, SHA-256 매니페스트.
- 설치 절차와 현장값 관리 방식은 바뀌지 않았습니다. 현장값은 `~/.njh-cli/site.env` 한 파일에만 두고, 설치 명령은 용량 확인 → 전체 사전 점검 → 실제 설치 순서를 그대로 따릅니다.

## 수신자 관점의 주요 변화

- **새 도구 `parallel_run`**: 모델이 대화에서 병렬 실행을 직접 부릅니다. 유닛 JSON 파일(`{"units":[{label,prompt}],"concurrency","harvest"}`)의 프롬프트들을 서브에이전트로 동시에 돌리고 전부 끝나면 유닛별 결과 표와 다음에 돌릴 회수 명령을 돌려줍니다. Vue 3 초안 킷 48차와 짝: njh 를 Vue 3 브랜치 폴더에서 열고 "5단계에서 거부된 화면들 병렬로 고쳐줘" 라고 말하면 모델이 유닛 생성 → `parallel_run` → 회수(검증·파일별 커밋)까지 순서대로 진행하고 집계를 보고합니다. 슬래시 명령을 칠 필요가 없습니다. `docs/tools-reference/parallel_run.md`.
- **`vue3-migration` 스킬 지침**에 위 순서(킷 경로 `~/.vue3-draft/kit-path` → `--njh-parallel` → `parallel_run` → `--harvest`)와 동시 수 안내(사내 DevAI 는 2~3 이 실효 상한)를 추가했습니다.
- 실행 파일 변경은 이 두 가지뿐이며 설치 절차·현장값 관리 방식은 바뀌지 않았습니다.

## 서버에서 돌리기 전에

- Node.js 요건은 `22.13.0+` 로 변함이 없습니다. 분리 미션·`/goal` 운용 절차는 `서버-운영-가이드.md` 가 정본이고, 미션이 커밋까지 하게 하려면 `미션-git-쓰기-정책.md` 의 두 스위치를 모두 켜야 합니다.
- 키는 환경 변수에만 넣고 설정 파일에는 환경 변수의 이름만 둡니다. 키 값, 호스트, 조직명은 문서·로그·설정 파일에 기록하지 않습니다.

## 설치 전에 확인할 것

- 이전 키트에서 안내한 사전 점검·보관·거부 규칙이 그대로 적용됩니다. 처음 설치하거나 절차가 기억나지 않으면 키트에 동봉된 `통합-설치가이드`와 `02-설치-및-업데이트` 문서를 먼저 읽으십시오.
- 기존 서비스 디렉터리는 삭제하거나 덮어쓰지 않고 시각이 붙은 형제 디렉터리로 보존되며, Ollama 모델 저장소는 그대로 유지됩니다.
