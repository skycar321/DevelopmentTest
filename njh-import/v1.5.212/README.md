## v1.5.211 → v1.5.212 델타

### 1. Codi 툴콜 — 역할 계약도 항상 전송 (마지막 겹 수정)
dev/prod Codi 앱이 일반 챗봇 프롬프트로 게시된 환경에서, 등록 플래그가 역할
계약("파일시스템에 접근하는 에이전트")을 생략해 모델이 "파일을 볼 수 없는
인터페이스"로 자기규정하던 문제 — **기본값을 전량 전송으로 전환**했습니다.
기존 설치는 킷 교체 없이도 `settings.json`의 `codiPlayground` 세 플래그를
`false`로 바꾸면 동일 효과.

### 2. 노트북 GPU 가속 자동화 (내장/외장)
vulkan 라이브러리를 넣어두면 `setup-local-llm.sh`가 **자동으로 CPU vs GPU를
측정 → 이득이면 채택 저장 → 이후 항상 그 모드로 기동**합니다(현장 실측:
prefill +3~4배, 생성 +38~48%). 강제 `--accel vulkan|cpu`, 재측정
`--remeasure-accel`. 외장 GPU도 같은 경로로 자동.

### 3. ollama 외부 조회 기본 차단
모델 추천 기능이 ollama.com을 조회해 사내 차단 페이지가 로그를 뒤덮던 것 —
서버·노트북 모두 `OLLAMA_NO_CLOUD=1` 기본.

### 4. 서버 설치 로그의 awk syntax error 소거
포트 소유 확인 표현식 문법 오류(판정은 폴백으로 정상이었음) 근본 수정.

## 설치
- **개인 PC/노트북 킷만 교체해도 됩니다.** 서버 3대는 오늘 설치한 v1.5.211
  그대로 운용 가능(4번은 로그 미관 문제, 다음 서버 교체 때 반영).
- DB는 기존처럼 `~/.bashrc`의 `sqms_jdbc_*` export로 자동 조립됩니다(추가 작업 없음).
