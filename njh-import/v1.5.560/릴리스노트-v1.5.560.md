## 이 키트가 담는 것

- v1.5.559(전 키트)의 기능 전체에 더해, 아래 변경이 들어갔습니다. 구성은 이전 정식 키트와 동일합니다: 클라이언트(njh-cli), 게이트웨이(njh-gateway), 노트북 검증 킷(njh-win-laptop), Ollama Windows CPU 런타임, OCR 엔진, 빌드 매니페스트, SHA-256 매니페스트.
- 설치 절차와 현장값 관리 방식은 바뀌지 않았습니다. 현장값은 `~/.njh-cli/site.env` 한 파일에만 두고, 설치 명령은 용량 확인 → 전체 사전 점검 → 실제 설치 순서를 그대로 따릅니다.

## 수신자 관점의 주요 변화

- **Vue 3 마이그레이션 스킬 갱신(랩 통합 tip 172c03a3)**: 공통 부품 9종(조회폼·AG Grid 껍데기·다이얼로그 껍데기·업무 다이얼로그·팝업 프레임·날짜·얼럿·첨부 테이블·탭)과 컴포저블 15종, 화면별 채택기 11종, 인프라 코드모드(router 4·Pinia·세션 identity), 원커맨드 초안 드라이버(`vue3_draft_project.mjs --assign-all`)가 번들됩니다. 랩 실측: as-is 152 화면 전체를 한 명령으로 변환해 `npm run build` 통과, 화면 단위 완전 전환 42·부품 반영 123.
- **번들 스킬은 비식별판**: 사내 화면 식별자가 든 랩 전용 화면별 드라이버·테스트는 이 키트에 넣지 않았습니다. 실제 사내 소스로 초안을 만들 때는 별도 반입 킷의 `skill/` 을 `VUE3_MIGRATION_SKILL_ROOT` 로 지정합니다.
- **도구 수정**: 커밋 helper 의 테스트 파티션 가드가 `src/scripts/service` 밖 테스트에는 매니페스트 재생성을 요구하지 않습니다. 릴리스 누출 검사에 검토된 스킬 소스 줄 8건(런타임 토큰 변수·합성 테스트 픽스처)이 정확 문자열 예외로 등록됐습니다.

## 서버에서 돌리기 전에

- Node.js 요건은 `22.13.0+` 로 변함이 없습니다. 분리 미션·`/goal` 운용 절차는 `서버-운영-가이드.md` 가 정본이고, 미션이 커밋까지 하게 하려면 `미션-git-쓰기-정책.md` 의 두 스위치를 모두 켜야 합니다.
- 키는 환경 변수에만 넣고 설정 파일에는 환경 변수의 이름만 둡니다. 키 값, 호스트, 조직명은 문서·로그·설정 파일에 기록하지 않습니다.

## 설치 전에 확인할 것

- 이전 키트에서 안내한 사전 점검·보관·거부 규칙이 그대로 적용됩니다. 처음 설치하거나 절차가 기억나지 않으면 키트에 동봉된 `통합-설치가이드`와 `02-설치-및-업데이트` 문서를 먼저 읽으십시오.
- 기존 서비스 디렉터리는 삭제하거나 덮어쓰지 않고 시각이 붙은 형제 디렉터리로 보존되며, Ollama 모델 저장소는 그대로 유지됩니다.
