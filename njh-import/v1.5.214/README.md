## v1.5.213 → v1.5.214 델타

1. **노트북 GPU 모드 영속(현장 확진 버그)** — 채택 후 자동 재기동이 구 CPU
   서버를 못 내리는 경우가 있어, 판정을 **Windows 사용자 환경변수(setx)로도
   영속**하고 종료 폴백(taskkill)을 추가. 이제 재부팅·수동 기동 등 어떤 경로로
   serve가 떠도 GPU 모드가 유지됩니다. (이미 수동 setx 하셨다면 결과 동일 —
   킷 교체는 다음 사람/재설치를 위한 것)
2. setup 실행 중 `NJH_SELF_DIR: unbound variable` 즉사 수정.
3. TUI 마감 4건: busy 라인이 길어도 경과초·ESC 안내 보존, 툴 반복 60초+ 구간에도
   대기 라인 표시, 스피너 고착 잔여 케이스 봉인, 보이지 않는 문자 인용줄 정리.
